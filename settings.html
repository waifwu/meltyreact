Play

What the original's Startup Menu set before the game started, and this browser port's own settings. The game reads its choices from its own files (app.cfg, cfg.cfg) in this browser's storage, so, as in the original, changes take effect the next time the game starts.

The game is running behind this windowpaused behind this page and reads these settings only when it starts. Save and restart saves them and starts the game again, which ends the match in progress. Esc or Close leaves without saving.

The game is running in another tab. It writes its settings back while it runs and would undo changes made here: close it first, then save.

Video mode

Stored in app.cfg as the original does. With full screen chosen the game runs its own full-screen mode (640×480 at the colour depth below). A browser only lets a page fill the screen after a click or a key press, so use the Full screen button on the game page or Alt+Enter; the button is marked when the game asks for it.The page then fills the screen at your first touch, in the browsers that allow it; there the game's Menu has a Full screen button as well. A copy that has never run starts windowed, where the original would start in full screen.

Color depth

The display mode the game asks for in full-screen mode. In windowed mode the game ignores it.

Controllers

The launcher's Controller 1 config, Controller 2 config and Controller defaults buttons (controller button assignment, stored in cfg.cfg) and keyboard keys are on the controls page.

Detailed configuration

Colour precision of the game's textures, by group, as in the original's Detailed configuration dialog. 16-bit textures show visible banding; 32-bit ones need more memory, which no longer matters, so the browser port starts with 32-bit everywhere. 16-bit is there for the original's look.

Problem evasion

Changes how some images are loaded and drawn: as single large (1024 × 1024) textures instead of the game's usual way. The original offered it to get around graphics-driver problems. In the port it made no visible difference in the scenes checked (title, menus, character select, a match). Off by default.

Game speed
frames per second; 60 is normal speed

The original resets this to 60 at every start, so it had to be set again each time. This page keeps it and the port enters it in the dialog at every start. Above the display's refresh rate the game still speeds up, but not every frame is shown.

This browser

Settings of the browser port that the original had no equivalent for. They are kept in this browser, apart from the game's files. The game page's URL parameters (?scale=, ?scaling=, ?smooth=, ?sound=, ?audioLatency=, ?mouse=) still override them.

Save

Reset puts the Startup Menu, Detailed configuration and browser settings back to what the browser port starts with: the game's first start, but with 32-bit colour and textures. It keeps cfg.cfg (your in-game options, keys, unlocks and records).

Export and import

The zip holds ReACT/app.cfg, ReACT/cfg.cfg and mbr-settings.json (this browser's settings). Importing replaces those files; cfg.cfg carries your progress with it.
