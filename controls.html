Controls

Play

Keys and controller buttons for both players. Changes are saved at once and reach a running game at its next frame.

For a controller or a keyboard connected to this device. The on-screen buttons need nothing here: their layout, size and macros are under Touch Controls in the game's Menu. Changes are saved at once.

Click a key, then press the new key (Esc or a second click cancels).Tap a key, then press the new key on a connected keyboard (a second tap cancels). A key already used elsewhere is swapped with the old one. F5, F11 and F12 stay with the browser. Esc is always a Pause key here, and never quits the game as it does in the original. The game's own Pause key is F5, and the game allows a pause only in some modes (Training Mode, for one).

    Connected controllers

      A browser shows a controller only after one of its buttons has been pressed while this page is open.

      Stick

      Button assignments are the game's own setting (cfg.cfg, the original launcher's "Controller config"): the game sees the first ten buttons of a controller only. The d-pad, a hat switch and the left stick all move the character; opposite directions pressed together resolve as on the keyboard (down beats up, left beats right).
